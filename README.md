# PROG6212-PART1-2-3
RaceDAY is a database system designed to manage and organise sporting events such as running, cycling, and walking competitions. The system stores information about users, events, event categories, participant enrolments, and race results. Users can have different roles, including Organiser, Participant, and Admin. Organisers can create and manage events, while participants can enrol in event categories and have their race results recorded. The database uses primary keys, foreign keys, unique constraints, and validation rules to maintain accurate and consistent data.
